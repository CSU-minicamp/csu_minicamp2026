# minicamp 2026 校园黑客松官网

面向中南大学学生的 `minicamp 2026` 校园黑客松活动官网原型，包含活动介绍、报名、个人中心、主办方管理后台与项目投票功能。

## 本地预览

项目不依赖第三方包。请确保已安装 Node.js，然后在项目目录执行：

```powershell
node server.mjs
```

在浏览器打开 `http://localhost:4173/`。

## 页面入口

- 官网首页：`/`
- 个人中心：`/profile.html`
- 项目投票：`/voting.html`
- 主办方后台：`/admin.html`

## 当前说明

这是可交互的前端原型，报名、个人资料、公告、分队与投票数据暂存于浏览器 `localStorage`。正式上线前应接入服务端、数据库、统一身份认证及权限控制。

## 技术栈

HTML、CSS、原生 JavaScript、Node.js 静态文件服务。
