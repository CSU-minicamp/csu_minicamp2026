WHAT IS MINICAMP

不是比谁写得最快，
而是看我们能一起做出什么。

minicamp 是一场面向中南大学学生的跨学科校园黑客松。这里不只需要程序员，也需要理解用户的人、会做设计的人、能讲清想法的人，以及愿意动手试一试的人。

你不需要提前准备成熟创意，也不必拥有完整团队。主题会在现场揭晓，人与想法在现场相遇，然后一起把它做出来。

HOW IT WORKS

从相遇，到交付。

Idea 必须现场产生。三个主题只用于激发灵感，所有作品进入同一个奖项池。

  1. 01MEET

    佩戴能力标签，在 Idea Collision 中找到你愿意共事的人。

  2. 02TEAM UP

    围绕一个真实问题组成 3–5 人小队，现场锁定项目方向。

  3. 03BUILD

    使用任意 AI Coding 工具开发，Mentor 与 Help Desk 全程在场。

  4. 04SHIP

    停止增加功能，完成可运行的 Demo 和三分钟舞台展示。

  5. 05CONNECT

    在 Demo Fair 体验作品、投票，并认识未来的项目伙伴。

FAQ / BEFORE YOU APPLY

报名前，
先把这件事了解清楚。

这里整理了参与者最需要确认的规则、准备事项和现场流程。如果你的问题没有被覆盖，可以通过报名页面提交给主办方。

不会编程，或者没有黑客松经验，可以参加吗？+

可以，而且我们明确欢迎非技术背景的参与者。 minicamp 不是只比较代码量或技术难度的编程竞赛。产品、设计、用户研究、商业、内容、硬件和其他跨学科能力，同样会直接影响一个项目能否真正完成。你可以负责发现问题、梳理需求、设计交互、验证用户反馈、组织展示，也可以在现场借助 AI Coding 学习并完成实现。活动会安排 AI Coding Quickstart 和持续开放的 Help Desk，帮助第一次使用相关工具的人从一个可运行的 Demo 开始。

大一新生可以参加吗？+

欢迎大一新生了解 minicamp、参加现场路演和项目展示，但按照本届活动安排，大一新生不参与两天的项目开发环节。其他年级不限制学院、专业或具体技术方向。我们更看重你的创造欲、参与动机、合作意愿和学习潜力，而不是年级或简历上的项目数量。

可以提前准备项目，或者带着成熟 Idea 来吗？+

可以提前了解活动、准备工具和思考自己想解决的问题，但不可以提前开发本届参赛项目。Day 1 现场会公布三个灵感主题，Idea 需要在现场产生、讨论和收敛。你可以带着一个模糊的问题或兴趣来到现场，也可以在 Idea Collision 中放弃原来的想法、加入别人的问题，或者和其他人共同形成一个全新的方向。

报名后，现场如何组队？最终队伍有几个人？+

报名资料提交后，现场会经历 Idea Spark、Idea Collision、Lightning Pitch 和 Team Market，帮助大家找到合适的合作伙伴。最终队伍标准为 3–5 人；Team Lock-in 时仍未完成组队的参与者，会由主办方根据兴趣和能力方向协助连接。

必须做 AI 产品吗？AI Coding 具体有什么要求？+

作品不要求包含 AI 功能，但所有团队需要在开发过程中使用 AI Coding。你可以使用 Codex、Claude Code、Cursor、GitHub Copilot、Gemini CLI 或其他 AI 编程工具。AI Coding 是开发方式，不是赛题；项目可以是网站、App、小程序、游戏、硬件、数据产品、创意交互，也可以完全不包含人工智能功能。主办方不会检查 Prompt、聊天记录或 AI 生成代码比例，只需要在项目提交时简单填写使用过的工具。

报名后应该提前准备什么？需要完成赛前作业吗？+

不设置赛前作业，也不要求提前完成练习。录取后会收到 AI Coding Starter Pack，内容包括推荐工具、安装和登录说明、基础环境准备、需求描述方法和常见报错处理。建议提前确认自己的电脑、网络、Node.js / Python / Git 等基础环境可以正常运行，并至少准备好一个计划使用的 AI Coding 工具账号。GitHub 或个人作品集是选填项，没有作品集不会影响正常报名。

报名如何录取？意向组队人员会不会影响个人录取？+

采用轻筛选 + 能力结构软控制，不会单纯按照竞赛奖项、简历长度或技术能力排名。主要关注创造欲、参与动机、合作意愿、能力或学习潜力，以及不同背景之间的多样性。每位报名者都会独立审核，填写的意向组队人员姓名仅用于现场连接参考，不影响个人录取判断。

两天活动具体会做什么？需要通宵吗？+

Day 1 约为 09:00–21:30，完成主题揭晓、创意碰撞、组队和主要开发；Day 2 约为 09:00–18:00，完成最后开发、项目提交、舞台 Demo、项目展览、投票和颁奖。活动安排不以通宵为前提，第一天会在 21:30 进行收尾。第二天 13:00 起停止新增核心功能，团队转入 Demo、部署和展示准备，重点是把作品稳定地交付出来。

项目可以做什么？最终需要提交哪些内容？+

项目方向不设单一技术赛道，可以围绕校园体验、真实用户需求或意料之外的创意进行尝试。最终提交包括 Team ID、项目名称、灵感主题、一句话介绍、成员及分工、Problem / Solution、Demo URL、项目截图或封面等；GitHub 链接可以自愿公开。Day 2 下午会进行约 3 分钟的 Stage Demo，展示重点是真实可运行的产品和核心体验，而不是长篇 PPT。

项目如何评审和投票？奖项可以重复获得吗？+

Best Overall、Best Product、Best Design & Experience、Best Technical Hack 和 Most Unexpected 等正式奖项通过参与者与 Jury 的投票综合产生，每位投票者对前三选择分别使用 3、2、1 票。People's Choice 只由参与者投票产生，且不能投给自己的团队。正式评审类奖项原则上一支团队最多获得一个；如果同一团队同时获得多个正式奖项，其他奖项会顺延给下一支符合条件的团队。People's Choice 可以与其他奖项叠加。

活动中遇到产品或技术问题，可以找谁？+

主办团队成员会在现场担任 Mentor / Connector，并通过队伍群聊和巡队提供支持。你可以咨询产品范围、用户问题、技术路线、AI Coding 工具、报错处理、Demo 风险、展示方式和测试用户等问题。Mentor 会帮助团队挑战假设、缩小范围和连接资源，但不会替团队决定方向，也不会替团队完成核心开发。

报名什么时候截止？录取结果什么时候通知？+

报名开放时间、截止时间和录取通知日期会根据筹备进度由主办方统一配置，并在官网状态、报名页面和通知渠道同步更新。提交报名后请确保联系方式准确，并留意后续通知。正式录取后，主办方会进一步发送队伍确认、AI Coding Starter Pack 和活动须知。
